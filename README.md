
# Aplikasi Penyimpanan Data Mahasiswa

## Deskripsi
Proyek praktikum Pemrograman Berorientasi Objek
mengenai pembuatan aplikasi desktop penyimpanan
data mahasiswa menggunakan Python, Tkinter,
dan SQLite.

## Teknologi
- Python 3
- Tkinter
- SQLite
- VS Code
- DB Browser for SQLite

## Fitur Aplikasi
1. Menambahkan data mahasiswa.
2. Menampilkan data mahasiswa.
3. Mengubah data mahasiswa.
4. Menghapus data mahasiswa.
5. Refresh data.
6. Validasi input.
7. Penyimpanan data secara permanen.

## Struktur Database
Nama database: mahasiswa.db

Nama tabel: mahasiswa

Kolom:
- id
- nama
- nim
- prodi
- alamat

## Cara Menjalankan
1. Pastikan Python sudah terpasang.
2. Buka terminal pada folder proyek.
3. Jalankan perintah:

   py aplikasi_mahasiswa.py
